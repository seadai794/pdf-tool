# pdf工具
这是一款完全免费、开源且无需安装的网页端效率工具箱。它最大的特点是 100% 纯本地运行 —— 你上传的所有文件、照片都不会被上传到任何服务器。没有网络限制，没有文件大小限制，彻底保护你的隐私安全。

无论是在电脑上处理工作文档，还是在手机上应急处理照片，只要打开网页，所有功能即刻可用。

🌟 核心亮点
🔒 绝对隐私安全：采用纯前端技术处理，所有数据仅在您的浏览器内运算，绝不联网传输。

⚡ 免安装即开即用：无需下载庞大的客户端，收藏网址即可随时随地使用。

📱 手机完美适配：针对移动端深度优化，支持调用手机摄像头拍照、全屏取景，甚至支持触摸手势拖拽。

🧩 工具箱化设计：整合了 11 项高频实用功能，覆盖文档、图片、证件三大场景。

🛠️ 功能全览
✏️ 1. 页面编辑 & 图像处理
📝 试卷拆分：专为学生和家长设计。一键将一张 A3 大纸上的对半或三等分试卷，智能拆分为 A4 单页。

✂️ PDF 裁剪：可视化拖拽裁剪框，去除 PDF 四周白边，支持统一输出为 A4 纵向或横向。

📄 页面调整：像整理扑克牌一样管理 PDF。支持页面随意拖拽排序、单页旋转、插入空白页或删除不要的页面。

📷 扫描文档：调用手机摄像头，自带文档增强算法（去阴影、提亮底色）。拍完可手动裁剪、旋转，一键合成高清 PDF。

🪪 2. 证件照及复印专属
🪪 身份证复印件：业内罕见的本地 A4 合成工具。带有专属的身份证比例取景框（人像在右、国徽在左上），拍完自动按真实物理尺寸（85.6mm × 54mm）排版到 A4 纸上，打印即用。

👤 证件照制作：告别去照相馆。支持自动裁剪人像，内置强大的 bordercut 涂抹抠图 引擎，你可以像“醒图”一样用手指涂抹去掉杂乱背景，然后一键更换白、蓝、红、灰底色，支持相馆 5 寸相纸拼版导出。

🔄 3. 格式转换
🖼️ 图片转 PDF：多选手机相册里的图片，支持调整顺序，自动适配 A4 排版合成一份 PDF 文件。

📷 PDF 转图片：将 PDF 每一页无损导出为高清 PNG 或 JPG 图片，支持一键打包 ZIP 下载。

📘 Word 转 PDF：上传 Word 文档（.docx），纯净提取文字和排版，通过浏览器原生打印完美转为 PDF。

📁 4. 文件操作
🔗 PDF 合并：将多个零散的 PDF 文件，按你设定的顺序拼接成一个完整的文件。

📑 PDF 拆分：将一份大文件，按设定的页数（如每 1 页、每 2 页）切分成多个独立的小文件，打包 ZIP 下载。
